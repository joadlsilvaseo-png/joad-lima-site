# Landing Page — Joad Lima / Design UX e UI

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: identidade visual, responsividade e animações.
- `script.js`: menu mobile, animação de entrada e ano automático.

## Antes de publicar

No final do arquivo `index.html`, procure por:

- `https://wa.me/5500000000000`
- `seuemail@exemplo.com`

Substitua pelo número de WhatsApp e pelo e-mail corretos.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador ou use a extensão Live Server no VS Code.
